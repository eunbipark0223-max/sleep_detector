# 졸음 가드 디자인 시스템 (11/19)

노디 AI 영상 「클로드로 디자인할 때 프롬프트부터 넣지 마세요」의 순서를 그대로 따랐다.

1. **레퍼런스 고르기** — Headspace (캐릭터가 있는 따뜻한 명상 앱 · 우리 부엉이 캐릭터와 어울림)
2. **토큰 뽑기 → 디자인 시스템** — Dembrandt 0.40.1 로 headspace.com 에서 실제 값을 뽑음
   (원본: `headspace_dembrandt_DESIGN.md`) → 애플 기준 · 우리 앱 색과 합쳐 아래 표로 정리
3. **한글 다듬기** — 화면 문구는 마침표 없이 · '-요' 말투 · 단어 중간에서 줄이 안 나뉘게

코드에서는 숫자를 직접 쓰지 않고 `lib/design_tokens.dart` 의 이름만 쓴다.

## 기사 앱이라 애플 · Headspace 와 다르게 둔 것

- 목록 한 줄 높이 44 → **50**, 큰 버튼 **48~53** (운전 중 · 장갑 낀 손으로 누르기 쉽게)
- 카드 둥글기 32 → **20** (목록이 많은 화면이라 너무 둥글면 산만함)
- 경고 화면 문장은 폭이 모자라면 글자만 작아지고 **꼭 한 줄**

## 캐릭터 일러스트 (11/19)

Headspace 의 동글동글한 캐릭터 일러스트 느낌을 빌려 **우리 부엉이**로 새로 그렸다 (그림 파일 없이 코드로 그림 — `lib/widgets/buddy.dart`, 값은 `design_tokens.dart` 의 `AppIllust`)

| 단계 | 색 | 표정 |
| --- | --- | --- |
| 0 정상 | 초록 `#6CC291` | 눈 뜨고 웃음 · 분홍 볼 |
| 1 주의 | 노랑 `#FFC53D` | 눈꺼풀이 반쯤 내려옴 · 입 일자 |
| 2 휴식 권고 | 주황 `#FF8A3D` | 눈 감음 · 하품 · z · 살짝 기울어짐 |
| 3 긴급 | 빨강 `#F2665A` | 깜짝 놀란 큰 눈 · 벌린 입 · 놀람 선 |

- 모양: 큰 돔 몸 + 바깥으로 기운 귀깃 + 눈 둘레 동그란 얼굴판 + 배 (반투명 흰색)
- 애플식 정리: 그라데이션 · 빛 번짐 없이 한 가지 색 · 얼굴은 끝이 둥근 선 하나 · 바닥 그림자는 번지지 않는 납작한 타원
- 움직임: 숨 쉬듯 2.4초마다 아주 살짝 위로 늘어남 (긴급은 0.9초로 빠르게) · 작은 아이콘은 멈춤
- 들어간 곳: 홈 · 운행 · 경고 · 휴식 · 시작 화면 · 가이드(단계별 4개) · 규정 도우미 · 리포트 · 운행 기록
- 로고 자리는 아직 네모 그대로

## 동그란 해 캐릭터 · Headspace 오늘 홈 (11/19 저녁 — 부엉이는 보류)

- 캐릭터 = 반투명 단계 색 동그라미 + 선 얼굴 (`Buddy`, 부엉이 판은 `OwlBuddy` 로 보관)
  - 색은 우리 단계 색(초록 `#2E9E5B` · 노랑 `#F2B01E` · 주황 `#F28C28` · 빨강 `#D93025`)에 투명도 — 몸 85% · 하늘 18% · 목록 그림 칸 14%
- 홈 큰 카드 = Headspace '오늘' 카드: 위 반투명 하늘 + 흰 언덕 뒤로 떠오르는 캐릭터, 아래 흰 칸에 날짜 · 큰 글 · 버튼 (둥글기 28)
- 홈 머리줄 = 시간대 인사(좋은 아침이에요 · 좋은 오후예요 · 편안한 저녁이에요) + 이름
- 경고 목록 = 왼쪽 네모 그림 칸(반투명 단계 색 + 작은 캐릭터)
- 탭바 = 흰 바탕 · 위 얇은 선 · 고른 탭은 진한 글자 + 굵게
- 운행 화면 카메라 = 화면 높이의 50% (버튼 칸을 196 → 76 으로 줄인 만큼)
