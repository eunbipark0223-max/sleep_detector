## 파일 형식 (새 문서를 넣을 때 지키기)

- 첫 줄 = 머리말. `|` 로 4칸을 나눕니다. 코드는 파일 이름이 아니라 **이 줄**을 읽습니다.
  - 법령: `법령명: … | 조항: … | 시행일: … | 출처 URL: …`
  - 일반 자료: `자료명: … | 조항: 해당 없음(…) | 발행일: … | 출처 URL: …` ← `해당 없음` 이 있으면 일반 자료로 분류
- 둘째 줄부터 본문. 항 · 호는 빈 줄로 나눕니다 (목 `가.` · 세목 `1)` 은 앞의 호에 붙여 하나로 취급).
- `[본조신설 …]` 같은 연혁 표기, `[이 자료에 없는 내용]` 같은 정리용 메모는 색인에서 빠집니다.
- 파일 이름은 **영문 · 숫자**로 (`law_` = 법령, `guide_` = 일반 자료). 한글 파일 이름은 도구가 못 여는 경우가 있음

## 주의

- **"2시간 연속 운전 → 15분 휴게"는 화물차와 시외 · 전세버스에만 해당**합니다. 시내 · 농어촌 · 마을버스는 1회 운행 기준(10분 등), 택시는 확인한 조문에 휴식 규정이 없습니다.
- 졸음운전을 이름으로 적은 조문은 없습니다 → 근거는 도로교통법 제45조의 "과로, 질병 또는 약물의 영향과 그 밖의 사유".
- 일반 자료 3개는 원문 전재가 아닌 **요약본**입니다. 정책브리핑 자료는 공공누리 제4유형(출처표시 · 상업적 이용금지 · 변경금지) → 발표 · 앱에 인용할 때 출처를 표기합니다. 도로교통공단 원문을 그대로 쓰려면 공단에 이용 조건 확인이 필요합니다.
- 아직 없는 것: 한국도로공사 · 한국교통안전공단 자체 자료, (가상) 회사 안전 매뉴얼
- 자세한 원문 확인 내용: 노션 「규정 원문 확인」
