## 파일 형식 (새 문서를 넣을 때 지키기)

- **파일 하나 = 조 하나.** 머리말의 조항으로 제목을 붙이므로 한 파일에 여러 조를 넣으면 제목이 틀어집니다.
- 첫 줄 = 머리말. `|` 로 4칸을 나눕니다. 코드는 파일 이름이 아니라 **이 줄**을 읽습니다.
  - 법령: `법령명: … | 조항: … | 시행일: … | 출처 URL: …`
  - 일반 자료: `자료명: … | 조항: 해당 없음(…) | 발행일: … | 출처 URL: …` ← `해당 없음` 이 있으면 일반 자료로 분류
- 둘째 줄부터 본문. 항 · 호는 빈 줄로 나눕니다 (목 `가.` · 세목 `1)` 은 앞의 호에 붙여 하나로 취급).
- `[본조신설 …]` 같은 연혁 표기, `[이 자료에 없는 내용]` 같은 정리용 메모, `※` 로 시작하는 문단은 색인에서 빠집니다.
- 조항 칸에 `벌칙` · `처벌` 이 있으면 주제 `penalty` — 경고 경로의 졸음 근거(제45조) 고정에 섞이지 않습니다 (제154조 제3호도 '과로' 를 담고 있음).
- 파일 이름은 **영문 · 숫자**로 (`law_` = 법령, `guide_` = 일반 자료). 화물 규칙은 `law_freight` 로 시작해야 화물차 규정으로 분류됩니다.
- 문서를 바꾸면 서버가 다음 검색 때 색인을 새로 만듭니다 (`chroma_db/`, 문단 약 100개 = 임베딩 무료 한도 분당 100 에 거의 닿음).

## 주의

- **"2시간 연속 운전 → 15분 휴게"는 화물차와 시외 · 전세버스에만 해당**합니다. 시내 · 농어촌 · 마을버스는 1회 운행 기준(10분 등), 택시는 확인한 조문에 휴식 규정이 없습니다.
- 졸음운전을 이름으로 적은 조문은 없습니다 → 근거는 도로교통법 제45조의 "과로, 질병 또는 약물의 영향과 그 밖의 사유".
- 법령은 저작권 보호 대상이 아니라(저작권법 제7조) 원문을 그대로 넣습니다.
- 정책브리핑 자료 2개는 원문 그대로 — 공공누리 제4유형(출처표시 · 상업적 이용금지 · **변경금지**) → 고치지 말고, 발표 · 앱에 인용할 때 출처를 표기합니다.
- 도로교통공단 보도자료는 "ⓒ KOROAD. All rights reserved." 라 원문을 넣지 않고 사실(통계 · 수칙)만 요약했습니다. 원문을 쓰려면 공단에 이용 조건 확인이 필요합니다.
- 범칙금 액수(도로교통법 시행령 별표 8)는 표라서 아직 없음 → '휴대전화 쓰면 범칙금 얼마' 같은 질문은 "확인되지 않습니다".
- 아직 없는 것: 한국도로공사 · 한국교통안전공단 자체 자료, (가상) 회사 안전 매뉴얼
